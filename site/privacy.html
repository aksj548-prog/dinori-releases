다이노리 개인정보 처리방침

시행일: 2026년 11월 19일

요약: 다이노리는 이름·이메일·연락처 같은 개인정보를 수집하지 않으며, 게임 기록은 사용자의 PC 안에만 저장됩니다.

1. 게임 프로그램(다이노리)이 다루는 정보

  • 키보드·마우스 입력 횟수 — 알이 자라고 공룡이 성장하는 데 쓰입니다. 어떤 키를 눌렀는지, 무엇을 입력했는지는 기록하지 않고 «눌린 횟수»만 셉니다. 이 횟수는 PC 밖으로 보내지 않습니다.
  • 게임 세이브 — 공룡, 아이템, 설정 등은 사용자 PC의 %APPDATA%\Dinori 폴더에만 저장됩니다.
  • 업데이트 확인 — 홈페이지에서 받은 베타판은 새 버전이 있는지 확인하기 위해 GitHub(github.com)에 최신 버전 정보를 요청합니다. 이때 개인정보는 보내지 않습니다. 마이크로소프트 스토어판은 업데이트를 스토어가 처리합니다.

2. 홈페이지 커뮤니티(다이노리 광장)

  • 채팅·글·댓글·스크린샷에는 사용자가 직접 입력한 닉네임과 내용이 공개적으로 표시됩니다. 개인정보를 올리지 마세요.
  • 도배·악용을 막기 위해 글을 쓴 접속 IP 주소를 서버에 저장하며, 이는 차단 목적에만 사용하고 공개하지 않습니다.
  • 닉네임은 사용자의 브라우저(로컬 저장소)에만 기억됩니다.
  • 삭제를 원하는 글이 있으면 아래 연락처로 알려 주세요.

3. 제3자 제공

다이노리는 정보를 판매하거나 제3자에게 제공하지 않습니다. 홈페이지는 Cloudflare, 설치 파일은 GitHub를 통해 제공됩니다.

4. 아동

다이노리는 개인정보를 수집하지 않으므로 연령과 관계없이 별도의 정보를 받지 않습니다. 커뮤니티에는 개인정보를 올리지 않도록 지도해 주세요.
